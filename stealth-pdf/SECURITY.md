# 安全策略 / Security Policy

## 受支持的版本

仅最新发布版本会收到安全修复。

## 报告漏洞

请**不要**在公开 Issue 中披露安全问题。请使用 GitHub 的私有漏洞报告：仓库的 **Security → Report a vulnerability**。报告中请包含：影响、复现步骤、涉及的版本。

我们会尽快确认并回复，修复发布后会在 `CHANGELOG.md` 中说明。

## 关于键鼠钩子

StealthPDF 使用系统级输入钩子判断触发键状态。设计承诺：

- 钩子回调只比较按键 / 鼠标键编号，不存储、记录或发送按键内容与鼠标轨迹；
- 程序不含网络请求与遥测。

任何违背以上承诺的行为都应视为安全问题，欢迎按上面的方式报告。
