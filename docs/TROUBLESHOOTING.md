# 常见问题排查 / Troubleshooting

先打开日志：托盘图标右键 →「打开日志文件夹」→ `stealth-pdf.log`。

## 窗口一直显示，不会隐藏

1. 触发键仍是**未绑定**的默认 Fn（键盘 Fn 通常无法被 Windows 检测）。「隐身」标签和状态栏里的触发键按钮会是黄色。点它，选一个键（推荐右 Alt）。
2. 隐身开关处于「关」。点「隐身」标签里的「隐身模式」或状态栏右侧的按钮，或按 `Ctrl+Alt+H`。
3. 刚启动：前 4 秒窗口始终显示。
4. 文件对话框正打开，或鼠标按键还按着（画笔 / 拖动中）。

## 按了触发键没有反应 / 窗口不出现

- 必须**同时**满足：按住触发键 **且** 光标在窗口范围内。窗口隐藏时请把光标移到它原来所在的位置。
- 记不清窗口在哪：托盘菜单 →「临时显示窗口 5 秒」或「把窗口移回屏幕中央」。
- 前台程序是以管理员身份运行的：请以管理员身份运行 StealthPDF（Windows 的 UIPI 限制）。
- 日志里出现 uiohook 加载失败：说明系统钩子没有启动，触发键无法工作；请重新安装或重新构建，并把日志贴到 Issue 里。
- 刚从锁屏 / 睡眠恢复：程序会重置触发状态，重新按一次即可。

## 录制触发键超时

按 Fn 没反应是正常的，见 README「关于 Fn 键」。换一个键，如右 Alt。

## 触发键带来副作用

系统钩子只能监听、不能拦截。见 README「已知限制」第 1 条，换用没有副作用的键。

## 点按钮没有反应 / 提示「组件未加载」

1. 看日志里是否有 `preload` 或 `did-fail-load` 报错。
2. 确认没有杀毒软件删除 `resources\app.asar` 或 `renderer\vendor` 下的文件，必要时重装。
3. 从源码运行时，请执行 `npm install` 后再 `npm start`。

## 鼠标滚轮不能翻页

请更新到最新版。若仍有问题，请在 Issue 中说明触控板还是鼠标、Windows 版本，并附日志。

## 中文文字标注保存后变成 `?`

程序在 `C:\Windows\Fonts` 下找 `simhei.ttf` 或 `msyh.ttf`。精简版系统缺少这些字体时，非 ASCII 字符会被替换为 `?`。

## 保存失败

日志里会有「保存失败」及原因。常见：文件被其他程序占用 / 只读，或 PDF 已加密。可先「另存为」到别处。

## 窗口跑到屏幕外

托盘菜单 →「把窗口移回屏幕中央」。

## 杀毒软件报警

程序使用全局键鼠钩子，个别杀毒软件会误报。可对照源码确认或自行构建，见 [BUILDING.md](BUILDING.md)。

## 构建问题

见 [BUILDING.md](BUILDING.md)「常见构建问题」。

## 还是没解决？

到 Issues 新建问题，请附：Windows 版本、StealthPDF 版本、复现步骤、日志相关片段（先去掉其中的个人路径）。
